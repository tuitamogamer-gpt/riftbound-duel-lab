# The arcane collection

Three original card backs generated with OpenAI image generation for the Duel Lab
interface. The collection uses a shared obsidian field and champagne-gold frame:

- **Riftglass** — teal crystalline rift.
- **Moonveil** — violet opal and opposed crescents.
- **Sunforge** — amber crystal and eight-point sun.

Artwork contains no card identity, text, branding, or character imagery. Generated
originals were encoded as 744 × 1039 WebP images for local loading and offline use.
The application's card-back preference is cosmetic and local to the device.

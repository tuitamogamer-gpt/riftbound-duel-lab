Dragon Roost provides an optional destination permission without removing other restrictions. Patched Porobot remains unsupported because its combined Unit/Gear type needs engine support.

Smite and the remaining unsupported entries stay unavailable. Existing constructed-ban flags remain unchanged; executable support does not imply tournament legality. The complete ID ledger below and the coverage report define the scope.
